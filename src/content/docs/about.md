# 关于

一个写给自己看的博客。内容主要是工作之外的技术折腾：自建服务、静态站、AI 工具，偶尔写点没想清楚的东西。

## 这里不写什么

- 公司项目和客户相关的任何内容——那些放在另一个只在公司内网可见的站点里。
- 转载和不加验证的二手结论。

## 怎么做的

[Astro](https://astro.build) + Starlight 主题，全站静态生成，托管在 Cloudflare Pages。源码在 GitHub，写作在 Obsidian 里完成，提交即发布。

搭建过程记在[第一篇](/tinker/why-static-blog/)里。

## 联系

站内没有评论区，想聊可以直接发邮件，或者在 GitHub 上提 issue。
