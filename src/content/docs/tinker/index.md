# 折腾

自己动手装过、跑通过的东西。写的是过程和判断，不是「三步搞定」的清单。

## 文章

- [我为什么把博客做成了静态站](/tinker/why-static-blog/) —— 从选型到上线，三个弯路和两个坑

## 写这类东西的原则

1. **先写清楚为什么**，再写怎么做。方案会过时，判断不会。
2. **命令必须能直接复制跑**，占位符用 `<尖括号>` 标出来。
3. **失败的尝试也写**。读者最需要的往往不是正确答案，而是「这条路走不通」。
